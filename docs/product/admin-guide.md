# 管理员操作手册

> 文档类型：操作手册。复核日期：2026-11-28。管理操作会修改对应环境的 KV；执行前确认当前打开的是 Staging 还是 Production。

## 1. 管理入口与认证

进入页面顶部的「数据源管理」或「适配器管理」。未认证时输入对应 Worker 的管理员令牌。令牌仅用于当前页面内存，不应保存到浏览器持久存储、前端环境变量或 Git 仓库。

Staging 和 Production 使用不同 Worker、KV 与管理员令牌。当前项目开发和验收以 Staging 为准；不要在未获授权时操作 Production。

## 2. 适配器管理

适配器元数据与可执行代码是两回事：

- Worker 代码中的 Provider registry 是可执行实现的白名单。
- KV 中的适配器记录负责管理显示名称、备注和启用状态等元数据。
- 在页面中「新增适配器」只登记元数据，不会生成代码或解析器。
- 未在 Worker registry 中实现的适配器不能启用，也不能被 Provider 数据源使用。
- 修改协议、解析逻辑、支持能力或实现版本需要改代码并部署 Worker；单纯修改允许的管理元数据通常只写入 KV。

### 登记内置适配器

使用「登记内置适配器」会将当前 Worker 已编译实现的适配器登记到当前环境 KV。操作具有幂等性，新登记的适配器保持禁用；它不会自动创建或启用任何数据源。

### 启用或禁用

启用前确认 Provider 实现已部署、来源兼容性成立，并完成来源级别审查。若某适配器仍被启用的数据源引用，系统会阻止禁用。删除仍被数据源引用的适配器也会被拒绝。

## 3. 数据源管理

数据源分为两种：

- **Worker 抓取源（Provider）**：Worker 根据已部署的适配器请求来源 API、RSS 或经审查的 HTML 页面。
- **外部搜索 / 站点入口**：只生成用户主动打开的 HTTPS 搜索链接或主页，不由 Worker 抓取，也不能执行 Worker 单源测试。

### 登记来源

1. 在预置来源目录中找到目标来源，或创建自定义来源。
2. Provider 类型必须先登记并启用兼容的已部署适配器。
3. 填写唯一来源 ID、名称、来源类型、内容分类、基础 URL、支持的搜索模式和能力。
4. 按 Provider 实际实现选择能力，不要仅因来源页面展示了某字段就声明 Worker 已支持。
5. 新来源默认应保持禁用，直到完成来源条款、访问规则、Cloudflare Worker 连通性和结果映射审查。
6. 保存后检查来源列表中的配置和状态。

外部搜索候选可以批量登记，但批量导入仅接受保持禁用的 external-search 记录。它们不会被 Worker 请求。

### 修改与删除

修改或删除会更新当前环境的 KV。保存时使用 ETag 版本前置条件；如果出现版本冲突，先刷新最新配置，再重新编辑，不要覆盖其他管理员刚保存的内容。

删除来源会从当前配置移除记录。删除前确认没有依赖该来源的字段优先级设置或运维记录。

## 4. 来源测试

只有启用的 Provider 来源可以执行测试；外部搜索来源不支持 Worker 测试。

- **测试连接**：使用固定探测词执行一次有界 smoke search。它不是 TCP ping。有效响应即可能成功，即使结果数为 0。
- **测试搜索**：使用管理员指定的查询词和支持的模式，执行单来源搜索。
- 诊断显示状态、耗时、结果数和最多三个样例。样例不包含完整资源链接或媒体元数据。

测试操作不会修改来源配置或启用状态。成功仅说明当时请求获得有效 Provider 响应，不代表来源条款已获批准，也不代表应当启用来源。

## 5. 字段来源优先级

字段优先级控制聚合结果中标题、番号、发行日期、封面、简介及 metadata 子字段优先采用哪些来源。

- 每个字段可以配置来源 ID 顺序。
- 排在前面的来源优先；未列出的来源按数据源列表顺序处理。
- 空数组或未配置时沿用默认来源顺序。
- 只填写已登记来源 ID；不要把外部来源或不存在的 ID 当作有效 Provider 优先级。

## 6. 安全操作清单

- [ ] 确认当前环境是 Staging，不是 Production。
- [ ] 不把管理员令牌或 API Secret 写入来源备注、KV 明文、截图或聊天。
- [ ] 不启用仅有目录条目但尚未实现的来源。
- [ ] 不绕过登录、付费墙、CAPTCHA、反机器人挑战、地域限制或限流。
- [ ] 对每个来源单独记录政策审查和技术验证结论。
- [ ] 禁用来源时先检查其关联适配器与字段优先级。
- [ ] 任何启用操作都应有明确授权和可追溯理由。
