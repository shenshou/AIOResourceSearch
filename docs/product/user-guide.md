# 产品概览与用户指南

> 文档类型：使用手册。适用版本：当前仓库实现。复核日期：2026-11-28。

## 1. 产品是什么

AIOResourceSearch 是多分类、多来源的聚合检索入口。用户提交一个查询，选择内容分类和检索模式，系统向已启用且兼容的 Worker 数据源发起请求，统一整理结果并展示来源链接。

项目不托管、下载或播放媒体文件，也不是本地媒体库或下载器。结果中的资源链接由来源提供；打开后由用户前往原始站点或资源目标。

成人/JAV 搜索是项目核心方向之一，不是可选的边缘功能。其他内容分类用于扩展同一套聚合搜索能力。

## 2. 页面导航

顶部导航包含：

- **聚合搜索**：提交查询并查看多来源结果。
- **数据源管理**：管理员维护来源配置、启用状态、搜索模式、字段优先级和来源测试。
- **适配器管理**：管理员维护 Worker 已实现适配器的登记信息和管理状态。

管理页面需要管理员令牌。普通搜索不需要管理员登录。

## 3. 执行搜索

1. 打开「聚合搜索」。
2. 输入 1–120 个字符的查询词。
3. 选择内容分类；选择「全部」会请求所有匹配分类的已启用来源。
4. 选择搜索模式：
   - **番号**：适用于明确支持番号检索的来源。
   - **关键词**：适用于文本关键词检索的来源。
5. 点击搜索并查看结果。
6. 根据结果卡片上的来源和外链信息，判断是否打开原始站点。

注意：界面选择的搜索模式必须同时受到数据源配置和实际 Provider 实现支持。某个 Provider 只支持关键词时，不应把番号输入当成独立番号查询能力。

## 4. 如何理解搜索结果

- 每条结果会标注来源信息。
- 标准字段可能包括标题、详情页 URL、发行日期、封面和描述；具体字段取决于来源能力及字段优先级配置。
- 部分来源可能提供 Magnet、ED2K 或其他资源链接。是否出现取决于来源实现和配置。
- 聚合结果会进行 URL 去重和字段归一化；不同来源的同一作品不保证能够完全识别为同一实体。
- 搜索结果不等于来源背书，也不代表来源内容已通过人工核验。

## 5. 无结果或来源报错

无结果不一定代表 API 故障，可能原因包括：

- 查询词不匹配该来源的索引方式；
- 当前分类或检索模式不受来源支持；
- 来源没有对应记录；
- 来源暂时不可用、限流或超时；
- 数据源或适配器尚未启用。

普通用户可以更换关键词、分类或检索模式。管理员可使用来源管理中的单源测试诊断。不要把「连接测试成功但结果为 0 条」理解为该来源中存在目标记录；连接测试只证明探测请求获得了可接受响应。

## 6. 隐私与产品边界

当前产品没有用户账号、云端收藏、搜索历史、媒体托管或跨设备个人数据同步。管理员令牌只在管理页面会话内存中使用，不应通过截图、工单或聊天消息分享。
